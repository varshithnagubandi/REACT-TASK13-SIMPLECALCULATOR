# React Calculator App 🧮

A simple calculator built using React that can evaluate mathematical expressions using the `mathjs` library.

## 🚀 Features

- Input field to type custom expressions
- Number and operator buttons for quick input
- Real-time result evaluation
- Clear input functionality

## 🛠️ Technologies Used

- ReactJS
- JavaScript
- mathjs (for expression evaluation)
- CSS for basic styling
